Accent rule

Shu asserts. Used on one element per screen as a maximum. A signature, a status, a press. Never as background fill across an article surface. When in doubt, the ink does the work.

Alpha composition

--shu-rgb: 200 40 28
background: rgba(var(--shu-rgb) / 0.16);

Channel-triplet token paired with the hex so the same accent can sit at any alpha without hardcoded channels.

Cinematic across the board. Curves only — no spring physics. The studio's tactile spring set is reserved for future high-touch primitives; everything here authored as a deliberate, scripted move. The three durations cover hover/press, state change, and orchestrated reveal. Anything past one second justifies itself in writing.
