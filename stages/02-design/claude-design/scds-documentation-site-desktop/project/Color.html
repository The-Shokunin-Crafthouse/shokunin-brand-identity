Color · the room and the signal

Color earns its place by doing work.

Two warm grays carry the room. One vermilion does the signaling. Status pulls its hue from outside the brand band so the brand and the danger can never be confused. Every value below was placed to solve a specific problem.

iThe room · warm-gray ladder

Thirteen steps. One hue. Built to absorb friction.

The page sits at warmGray.100. Ink sits at warmGray.800. The other eleven steps exist so the surface between them never has to fight to read.

No pure whitewarmGray.25 (#F8F6F2) is the lightest value in the system. Pure white is not a token.
No pure blackwarmGray.900 (#0D0C0B) is the deepest. The warmth at the extremes is the signature.

iiThe signal · 朱 shu

One vermilion. Three jobs. Nothing else.

Shu marks the cursor's intent — hover, focus, the studio mark's accent surface. If you catch it doing decorative work on a page, the page is wrong.

Used sparinglyTwo intentional moments per page is the ceiling. Three is decoration.
Not errorShu is brand-vermilion. The error status is a separate oxblood — see the row below.
The mark itselfThe studio mark never resolves to shu. Only the small accent cell in the lockups carries it.
iiiOutside the band · status

Four independent hues. None of them shu.

Error is oxblood, not red. When a screen says danger, the brand and the warning cannot be mistaken for each other. Each status carries a light pair and a dark pair, both calibrated AA on the ground beneath them.

Why oxbloodError must read as serious. Shu reads as bright. If both occupy the same hue band, the page lies twice — once about brand, once about danger.
Color is not the only carrierEvery status pairs a hue with a copy register and an alert stamp. Pull the color and the message still reads.
