# Drams UI sounds

UI sounds from [Drams](https://drams.framer.website/) by 1042.Studio (@mrblackstudio, @karimeshrimp), retrieved 2026-10-07.

## License

Drams permits use in personal and commercial projects with a credit ("Just give us a shoutout if you do so"). Do not redistribute modified versions as your own. Any surface that ships one of these sounds credits Drams.

## Contents

- `manifest.json` lists every file: duration, size, the Drams page that uses it, and the original asset URL.
- File names follow `drams-<component id>[-<component name>]-<nn>`. The id is the page at `https://drams.framer.website/drams/<id>`. A name appears only where Drams publishes one or the component type is confirmed.
- `sk2-*` files come from the `/sk2` experiment page.
- Six long tracks (16 s to 392 s of music and ambience) are not UI sounds and are not included. `manifest.json` lists them under `skipped`.

## Deploy scope

This folder sits outside `public/`, so the brand site deploy (`dist/`) does not publish it. Copy a sound into a component or into `public/` only after it is selected.
